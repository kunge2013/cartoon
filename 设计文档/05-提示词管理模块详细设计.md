# 05 - 提示词管理模块详细设计（★ 重点模块）

> 定位：全项目的**地基模块**（Phase 1 实现）。所有 AI 能力（角色推导/文案改写/分镜拆分/图片提示词推导/视频提示词/小说评分）都是"提示词资产 × 上下文"的组合，本模块统一管理前者，并与 [06-提示词拼装引擎设计.md](06-提示词拼装引擎设计.md) 配合消费后者。

## 一、概念模型：五件套

```
┌─────────────────────────────────────────────────────────────┐
│ prompts            提示词库：成品指令（对标源库 13 条，可整段使用） │
│ prompt_snippets    片段库：可复用小块（负面后缀/画风前缀/质量词）    │
│ prompt_templates   模板库：带 {{变量}} 占位符的阶段主体指令          │
│ prompt_presets     预设：阶段+模板+槽位值的组合（可选可切换）        │
│ prompt_render_logs 渲染历史：每次拼装留痕，可回放调试               │
└─────────────────────────────────────────────────────────────┘
关系：preset ──使用──► template ──引用──► snippet；preset+context ──渲染──► rendered ──记录──► render_logs
```

## 二、数据模型（DDL 见文档 04 §3.1，此处讲语义）

### 2.1 prompts（提示词库条目）

- `category`：沿用源分类（场景描述/角色设定/画风描述/对话生成/情节发展/VIP）+ 用户自建分类；
- `purpose`：绑定业务阶段（§1.2），供"该阶段选提示词"下拉使用；
- `variables_json`：声明式变量 `[{"name":"novel_text","desc":"小说正文","required":true}]`，编辑器据此生成表单；
- `is_system=1` 的条目：可编辑副本（fork），原条目锁定不可删（对标源 builtin_prompts_seed/builtin_prompt_guard 思想）。

### 2.2 prompt_snippets（片段）

- `tag` 字典（首期）：`negative`（负面）、`style_prefix`（画风前缀）、`quality`（质量词）、`portrait_render`（三视图渲染）、`layout`（版式约束）、`custom`；
- 片段是**全局唯一内容源**：改一处，所有引用它的预设/模板下一渲染即生效（解决源系统硬编码散落问题）。

### 2.3 prompt_templates（模板）

- Jinja2 语法，例（image_derive 主体，对标三段式产出要求）：

```jinja
你是一位顶级条漫分镜画师。请把下面的分镜内容推导为一条图片生成提示词，严格输出三段，用空行分隔：
第一段：{{ style_prefix }}开头，描述多格构图与画面内容；
第二段：版式逻辑详解：格子比例、阅读动线、色彩规范、字框样式（白底黑边黑字 #1a1a1a）；
第三段：逐字输出 {{ negative_suffix }}。

【画风】{{ style_prefix }}
【项目摘要】{{ project_summary }}
【角色卡】
{% for r in roles %}{{ r.name }}：{{ r.content }}
{% endfor %}【前情分镜】
{% for s in prev_shots %}第{{ s.order }}镜：{{ s.content }}（画面：{{ s.image_prompt | truncate(120) }}）
{% endfor %}【本镜内容】{{ shot_content }}
【项目前缀】{{ project_img_prefix }}
【项目后缀】{{ project_img_suffix }}
【自定义指令】{{ custom_1 }}
```

### 2.4 prompt_presets（预设）

- `id` 语义化（`plot_manga_fusion_bw`、`storyboard_short_v1`…）；
- `slots_json`：`{"custom_1": "...", "attach_snippets": ["negative_watermark", "style_korean_webtoon"]}`；
- 每个 stage 允许 `is_active=1` 的预设**至多一个**（对齐源"每阶段一个激活预设"）；
- 系统/用户预设同表，`is_system` 区分。

### 2.5 prompt_render_logs（渲染历史）

- 记录：preset_id、stage、context_json（变量快照）、rendered（成品）、target_table/target_id（如 scripts/123）；
- 用途：回放调试（"这一镜的提示词当时是怎么拼出来的"）、审计、效果回归对比。

## 三、API 设计（前缀 /api）

### 3.1 提示词库

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/prompts` | 分页列表，过滤 `?category=&purpose=&keyword=&is_system=` |
| POST | `/prompts` | 新建 |
| GET | `/prompts/{id}` | 详情 |
| PUT | `/prompts/{id}` | 更新（system 条目自动 fork 为用户副本，返回新 id） |
| DELETE | `/prompts/{id}` | 删除（system 拒绝） |
| POST | `/prompts/{id}/fork` | 复制为可编辑副本 |
| GET | `/prompt-categories` | 分类列表（含计数） |
| POST | `/prompt-categories` | 新建分类 |
| POST | `/prompts/import` | JSON 导入（用于迁移源库） |
| GET | `/prompts/export` | JSON 导出（可按分类/purpose 过滤） |

### 3.2 片段 / 模板 / 预设

| 方法 | 路径 | 说明 |
|------|------|------|
| GET/POST | `/prompt-snippets` | 列表（过滤 tag）/ 新建 |
| PUT/DELETE | `/prompt-snippets/{id}` | 改 / 删 |
| GET/POST | `/prompt-templates` | 列表（过滤 stage）/ 新建 |
| PUT/DELETE | `/prompt-templates/{id}` | 改（version+1）/ 删 |

| GET/POST | `/prompt-presets` | 列表（过滤 stage）/ 新建 |
| PUT/DELETE | `/prompt-presets/{id}` | 改 / 删 |
| POST | `/prompt-presets/{id}/activate` | 激活为该 stage 当前预设 |

### 3.3 拼装调试（详见文档 06）

| 方法 | 路径 | 说明 |

## 四、界面设计（Element Plus）

### 4.1 提示词库页 `/prompts`

- 左栏：分类树（系统分类+自建，计数徽标）；
- 主区：表格列 [标题 | 分类 | 阶段 purpose | 系统/用户 | 更新时间 | 操作(编辑/复制/删除/导出)]；
- 抽屉编辑器：标题/分类/阶段/内容（CodeMirror，等宽字体，行号）；底部"变量声明"自动解析 `{{var}}` 生成表格（名称/说明/必填）；
- 顶栏：搜索框、"新建"、"导入 JSON"、"导出"。

### 4.2 预设管理页 `/presets`（与库分开，避免概念混淆）

- 按 stage 分组的卡片/表格：每阶段一行，显示当前激活预设 + "切换"；
- 预设编辑：选模板（下拉，同 stage）+ 6 个自定义槽位输入（对标 derive_custom_slot_1..6）+ 附着片段多选（negative/style_prefix…）；
- "试一试"按钮 -> 打开拼装调试抽屉。

### 4.3 拼装调试台 `/assemble`（本模块亮点）

- 左侧：stage 选择 -> preset 选择 -> 上下文变量表单（依据模板 variables 自动生成；支持粘贴 JSON 一次填充）；
- 右侧：渲染结果**分段高亮**（system/context/negative 不同底色）+ 复制按钮 + "查看渲染历史"；
- 底部：一键"用真实项目数据填充"（选项目/选分镜，从库里拉真实上下文）。

### 4.4 片段库页 `/snippets`

- 按 tag 分组的表格；编辑同库条目；启用开关。

## 五、种子迁移方案（Phase 1 交付物）

1. 从 `_inspect/prompts.json` 全量导入 13 条 -> prompts（is_system=1，保持源 category）；
2. 拆出片段：
   - 负面水印后缀（scripts_list.image_prompt 第三段逐字）-> snippet(tag=negative, name=平台水印禁令)；
   - prompts#5"顶级韩漫风格…"-> snippet(tag=style_prefix, name=图片推导默认前缀)；
   - 三视图公共渲染词（roles.content_word2 中"strictly isolated on a pure white background…"段落）-> snippet(tag=portrait_render)；
3. 建首期 6 预设：`role_derive_vip`、`storyboard_short_v1`、`storyboard_long_v1`、`dialogue_split_v1`、`rewrite_v1`、`plot_manga_fusion_bw`（image_derive）；
4. 预设激活状态对齐源 settings：image_derive -> plot_manga_fusion_bw。
5. 导入工具：`POST /api/prompts/import`（幂等：按 title+category 去重）。

## 六、非功能与护栏

- **保护**：is_system 条目不可删、直接编辑即 fork（不破坏升级种子）；种子重导幂等；
- **并发**：SQLite WAL 模式；提示词编辑低频，无热点；
- **校验**：模板保存时 Jinja2 语法编译校验 + 未声明变量警告（variables_json 与 body 双向核对）；
- **测试**：拼装引擎纯函数单测（渲染快照测试：固定 context -> 固定 rendered）；种子导入幂等测试。
