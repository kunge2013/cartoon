```bat
:: 创建（已完成）
conda create -n catong_gen python=3.11 -y

:: 激活
conda activate catong_gen

:: 位置
:: D:\Users\ThinkPad\miniconda3\envs\catong_gen  (Python 3.11.15)
```

`environment.yml`（仓库内，可重建）：

```yaml
name: catong_gen
channels: [defaults]
dependencies:
  - python=3.11
  - pip
  - pip:
      - -r backend/requirements.txt
```

## 四、启动脚本（scripts/）

```bat
:: scripts/dev.bat  -- 后端
@echo off
call conda activate catong_gen
cd /d %~dp0..\backend
uvicorn app.main:app --reload --port 8300

:: scripts/dev-frontend.bat -- 前端
cd /d %~dp0..\frontend
npm run dev   :: Vite 默认 5173，proxy /api -> 8300

:: scripts/seed.bat -- 种子导入（提示词13条/片段/预设/标签/画风库）
call conda activate catong_gen
python -m app.seeds.seed_all
```

- 后端地址：<http://127.0.0.1:8300>（OpenAPI 文档 `/docs`）
- 前端地址：<http://127.0.0.1:5173>

## 五、配置（app/config.py）

| 配置 | 来源 | 默认 |
|------|------|------|
| DB_URL | env `CATONG_DB_URL` | sqlite:///./data/catong_gen.db |
| OUTPUT_DIR | env | ./Output |
| LLM 默认供应商 | settings 表 `llm_default_provider` | deepseek |
| 图像默认 | settings 表 | grsai / nano-banana-2 / 3:4 / 2K |
| 并发上限 | settings `image_batch_concurrency` | 5（对齐源库 manga_batch_concurrent_limit） |
| 日志 | env | logs/backend.log，轮转 10MB |

## 六、开发约定

1. **分支/提交**：`feat/phase1-prompt-module` 等按阶段建分支；提交信息 `phase1: prompt crud`；
2. **迁移**：模型改动必须 `alembic revision --autogenerate`；
3. **测试**：拼装引擎渲染快照测试必须随模板变更同步更新；
4. **API 文档**：routers 内 docstring 即文档（FastAPI 自动聚合）；
5. **不做的事**：不加用户体系/权限（单机自用）；不引入 Redis/Celery/Docker（保持 conda 即环境）。
