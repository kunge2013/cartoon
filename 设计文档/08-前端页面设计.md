# 08 - 前端页面设计（Vue3 + Element Plus）

## 一、路由与信息架构

```
/                       工作台（最近项目/快捷入口/流程引导）
/novels                 小说中心
/novels/{id}            小说详情（多标签页正文 + AI 阶段流水线）
/roles                  角色中心（按小说筛选）
/projects               项目列表
/projects/{id}          项目工作区（分镜编辑器）
/prompts                ★ 提示词库
/presets                ★ 预设管理（按阶段）
/snippets               ★ 片段库
/assemble               ★ 拼装调试台
/art-styles             画风库
/settings               设置中心（供应商/生成参数）
```

## 二、核心页面布局

### 2.1 工作台 `/`

- 步骤引导卡片（核心流程 7 步，点击直达对应页面）；
- 最近项目表格；快捷"新建小说/新建项目"。

### 2.2 小说详情 `/novels/{id}`

- 左：章节/标签页树（原文1、原文2…，可增删锚点）；
- 中：正文编辑器（等宽）；顶栏按钮：清洗（diff 抽屉预览）、角色提取、同义改写、分镜脚本（每个 AI 按钮可选择预设，默认取激活预设）；
- 右：AI 阶段流水线状态卡（character_text/revised_text/script_text 各阶段时间戳+重跑）。

### 2.3 项目工作区 `/projects/{id}`（最重页面）

- 头部：项目信息 + 画风选择 + 推导预设选择 + 项目前后缀编辑（抽屉）；
- 主体：分镜卡片流（虚拟滚动），每卡：
  - 内容文本（可编辑）；
  - image_prompt 折叠区（三段式高亮：画风段/版式段/负面段不同底色）+"重新推导"；
  - 候选图九宫格（点选主图，主图金框）；
  - 操作：生成（n 张）/ 锁定 / 启停生成 / 备注；
- 侧栏：批量操作（全选 -> 批量推导/批量生成/仅生成缺图）、任务进度（SSE 实时）；
- 底部工具条：导出长图 / 导出 ZIP。

### 2.4 提示词库 `/prompts`

（详见文档 05 §4.1：分类树 + 表格 + 抽屉编辑器 + 变量声明表）

### 2.5 拼装调试台 `/assemble`

（详见文档 05 §4.3：左变量表单/右分段预览 + 真实数据填充 + 渲染历史）

### 2.6 角色中心 `/roles`

- 顶部：选择小说 -> "AI 推导角色"（选预设）；
- 角色卡片墙：头像（三视图封面）、名称/别名、标签徽标、视觉描述摘要；
- 卡片操作：编辑（抽屉：描述/二稿/参考图上传）、生成三视图、删除；
- 标签字典管理（类型/时空）入口。

### 2.7 设置中心 `/settings`

- 分组表单：LLM 供应商（供应商+Key 池+默认模型）、图像供应商（model/ratio/resolution/超时）、生成参数（并发上限/重试）、导出目录、外观。

## 三、组件清单

| 组件 | 用途 |
|------|------|
| `PromptEditor` | 提示词/模板编辑（CodeMirror6，Jinja2 高亮，变量解析） |
| `SegmentedPromptView` | 三段式/多分段提示词渲染（分段底色 + 复制单段） |
| `PresetSelector` | 阶段预设下拉（含"管理"跳转） |
| `ContextForm` | 按阶段变量契约生成的动态表单 |
| `StoryboardCard` | 分镜卡（内容/提示词/候选图/操作） |
| `CandidateGrid` | 候选图九宫格 + 主图选择 |
| `TaskProgressDrawer` | SSE 任务进度抽屉 |
| `DiffViewer` | 清洗/改写前后对比 |
| `CategoryTree` | 提示词分类树 |
| `TagPicker` | 角色标签选择器 |

## 四、交互要点

1. 所有 AI 按钮旁都有 `PresetSelector`（默认激活预设），点击可临时换预设--"预设可换"是提示词体系的核心交互；
2. LLM 长任务统一：按钮 -> loading -> toast 完成通知；>3s 的操作走任务 + SSE；
3. 提示词任何展示位均可一键复制；image_prompt 三段用颜色区分，方便对照源应用格式；
4. 破坏性操作（重推导覆盖）弹确认，并说明 `prompt_touched` 保护策略。
